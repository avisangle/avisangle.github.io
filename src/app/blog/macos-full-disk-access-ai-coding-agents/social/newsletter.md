Apple said last week that macOS Full Disk Access will get harder to grant, and the reason it gave was AI agents. There's no date, no OS version and no detail on how it will work. I wanted to know what my own Mac lets a coding agent do right now, so I ran a few reads from the shell Claude Code uses.

Messages, Safari and Mail were blocked. My SSH folder was not. Claude Code doesn't ask for Full Disk Access at all, it inherits whatever your terminal was granted, and its sandbox is off until you turn it on.

If you run coding agents on a Mac, the post is a 15-minute audit with the exact settings I use. It also says what Apple hasn't told us, and I left out one deadline claim I couldn't trace back to Apple.
