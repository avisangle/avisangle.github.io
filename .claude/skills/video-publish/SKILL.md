# When to use

After `/video-render` produces the final MP4.

# Preconditions

- `video/out/<slug>/<slug>.mp4` exists
- `video/posts/<slug>/youtube.json` exists (generated by `/video-script`)
- `YOUTUBE_CLIENT_SECRET_PATH` set in `video/.env`
- `YOUTUBE_REFRESH_TOKEN` set in `video/.env`. If missing, run `npm run yt:auth` first.

# Steps

## 1. Read the metadata file

Read `video/posts/<slug>/youtube.json`. The upload script `youtube-upload.ts` is now fully data-driven — no inline editing needed.

If anything in the JSON needs a tweak (title length, description, tags), edit the JSON file directly. Common reasons to edit:
- Title is over 70 chars (Bing prefers under 70)
- Description is under-using the blog URL CTA
- Tags need to swap for higher-volume keywords after Search Console review

If `youtube.json` doesn't exist, the user skipped that step in `/video-script` — generate it now from `script.md` + `brief.md` and confirm with the user before continuing.

## 1a. Long-form: prepend chapter timestamps to description

If `youtube.json` has `"format": "long"` AND `video/posts/<slug>/chapters.json` exists, prepend a chapter timestamp block to the description (in-memory, before showing in step 2):

```
0:00 Hook
0:30 Context
2:15 The catch
4:00 What to do instead
6:30 Recap
8:20 Outro

<existing description body>
```

YouTube parses this format automatically — the first chapter must be `0:00`, each chapter ≥10s, listed in time order. Without this block the YouTube chapter UI does not appear, even with chapters.json on disk.

Save the modified description back to `youtube.json` so `/video-promote` and re-uploads see the same value, OR keep it in-memory and pass through to the upload script. Either is fine — pick one and be consistent.

## 2. Confirm with user

Show the metadata block (title + description + tags + privacy + playlist target from the JSON). Ask explicitly: **"upload" / "edit JSON" / "stop"**.

If the JSON has `playlistIds` or `playlistTitle`, surface that explicitly in the confirmation — appending to a series playlist is visible to subscribers and worth showing before pressing go.

**Critical rule:** do NOT upload without explicit user confirmation. Do NOT change `privacy` to `unlisted` or `public` in the JSON unless the user explicitly asks for that — `private` is always the safe default.

## 3. Upload

```bash
cd video && npm run yt:upload -- <slug>
```

The script:
- Reads `posts/<slug>/youtube.json` for title, description, tags, privacy, etc.
- Reads `out/<slug>/<slug>.mp4` as the source
- Calls `youtube.videos.insert` with the metadata
- Prints video ID, watch URL, and Studio URL
- If `youtube.json` has `playlistIds` (array of IDs) OR `playlistTitle` (string), appends the video to those playlists via `youtube.playlistItems.insert`. `playlistIds` wins when both are set. `playlistTitle` does a case-insensitive lookup of the user's own playlists and creates one if not found, matching the video's privacy. Failures are warned but do not roll back the upload.
- If `youtube.json` has a `compositionId` field AND `public/voiceover/<compositionId>/captions.srt` exists, also uploads it as the English subtitle track via `youtube.captions.insert`. SRT failure does not roll back the video upload — the video stays published, only the subtitle track is missing.

## 4. Capture and report

Print to user:
- Video ID
- Watch URL — `https://www.youtube.com/shorts/<id>` for `format: "short"`, `https://www.youtube.com/watch?v=<id>` for `format: "long"`. Default to Shorts URL if format is missing (legacy behavior).
- Studio edit URL: `https://studio.youtube.com/video/<id>/edit`
- Reminder: video is **Private** until user flips it

## 5. Suggest next

> Uploaded as Private. Video ID: `<id>`. Studio: https://studio.youtube.com/video/<id>/edit
>
> Manual steps remaining for you:
> - Set thumbnail in YouTube mobile Studio: scrub the frame picker to 0:00, the opening frame is the burned-in thumbnail (also available at `video/public/thumbnails/<slug>.png` for direct desktop upload if phone-verified)
> - Flip Private → Public when ready
>
> Next:
> - **Blog mode** (`youtube.json` has `blogUrl`): `/video-blog-embed <id>` to wire the YouTube embed into the source blog post
> - **Standalone mode** (no `blogUrl`): skip `/video-blog-embed` — there's no blog post to embed into. Promote directly via `/video-promote <id>` once available.

# Failure modes

- **401 invalid_grant** → refresh token expired or revoked. Run `npm run yt:auth` again.
- **403 quotaExceeded** → YouTube quota hit (10,000 units/day default; uploads cost 1,600 each). Wait 24 hours or request a quota increase.
- **400 invalid_video_metadata** → check title length (≤100), description length (≤5000), tags total (≤500 chars).
- **404 playlistNotFound** (playlist link step only) → `playlistIds` value is wrong or the playlist was deleted. Run `npm run yt:playlists` to refresh IDs. Video upload itself succeeded.
- **403 playlistOperationNotSupported** (playlist link step only) → trying to add to a playlist you don't own. Use `playlistTitle` to auto-create one under your channel instead. Video upload itself succeeded.
