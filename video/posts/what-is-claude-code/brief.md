## Hook

Most devs think Claude Code is a terminal CLI — it's actually six surfaces sharing the same context.

## Key bullets

- Six surfaces: terminal, desktop app, VS Code, JetBrains, web, mobile
- All hit the same engine — same prompts, same tools, same agents
- Sessions sync — start on laptop, monitor from your phone, resume in your IDE
- Mobile isn't a standalone app — it's Remote Control over a Claude Code session, plus claude.ai/code in browser
- Pick the surface for the moment — not lock in to one
