Google shipped Gemini 3.5 Flash last week, and it quietly beats Claude's own Opus 4.7 on the benchmark that matters most for agents: calling tools and chaining them together.

As a Claude Code user, I'm not switching — I'm routing. Here's the 60-second breakdown:

- Price: $1.50 in / $9 out per million tokens — about a third of an Opus agent loop
- Tool calling: ~84% on the MCP benchmark, past Opus 4.7
- The move: send tool-heavy planning to Flash, keep the actual repo edits on Claude Code

The catch nobody mentions: Flash defaults to high reasoning on every call, so a script you copied straight from the docs quietly burns 30–50% more on a long loop. Turn that one setting down to low and you get the price you were promised.
